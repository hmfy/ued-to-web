# 第三周：JavaScript 作业

本周只写 JavaScript。页面内容和样式已经准备好，请在 `script.js` 里完成页面操作。

## 开始方式

```bash
cp -R templates/week03 learners/<姓名拼音>/week03
cd learners/<姓名拼音>/week03
```

直接用浏览器打开 `index.html`，不需要安装依赖或启动服务。

## 练习内容

- 点不同的选项卡，让下面的内容跟着变化。
- 点击按钮打开弹窗，再用关闭按钮、暗色区域或 Esc 键关闭。
- 打开下拉菜单，选一项；点击菜单外面时关闭菜单。
- 输入商品名查找商品，按分类查看；没有结果时显示提示，点击商品可选中它。
- 给商品卡片加动画：滚动到商品列表时让卡片出现；搜索或切换分类后让卡片有变化。

HTML 和 CSS 不需要修改。按 `script.js` 里的练习顺序完成作业，并用浏览器检查每个按钮和菜单。
