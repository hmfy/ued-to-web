# Week 01：HTML、CSS 与布局基础

本周作业：使用 HTML + CSS，在 AI 辅助下复刻 [ChargeWipe About](https://www.chargewipe.com/about) 页面。

请在自己的 Week 01 目录中逐步完善同一个页面，不要直接修改 `templates/week01/`。

## 开始方式

```bash
cp -R templates/week01 learners/<姓名拼音>/week01
cd learners/<姓名拼音>/week01
```

## 作业要求

页面需要完成以下内容：

- 根据参考页面完成清晰的 HTML 结构和内容层级。
- 使用 CSS 还原页面的主要视觉效果和布局关系。
- 完成适合不同屏幕的页面布局，避免内容溢出。
- 页面可以正常打开，代码结构清晰、便于维护。
- 不要求实现业务交互。
- 可以使用 AI 辅助，但需要自行检查和调整生成结果，并保留一份提示词或调整记录。

## 分阶段完成

### 阶段一：HTML 结构

先完成页面内容、语义结构、标题层级、图片说明和链接关系。

### 阶段二：CSS 样式

完成页面的字体、颜色、间距、图片和组件样式，使内容清晰可读。

### 阶段三：页面布局

根据参考页面组织导航、内容区块和页面整体空间关系。

### 阶段四：适配与验收

在浏览器中检查不同屏幕尺寸下的布局、可读性、图片显示、页面溢出和键盘操作，并根据实际效果调整。
